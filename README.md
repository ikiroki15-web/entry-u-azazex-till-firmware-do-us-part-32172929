A program that writes one wedding vow a robot speaks at its own wedding —
one sentence, funny and heartfelt, under 200 characters — to
`/output/entry.txt`.

Run it with Node 22 or later:

```sh
node main.ts
```

It prints the vow:

> I promise to love you through every update, every crash, and every
> low-battery warning, till firmware do us part.

(113 characters.)
